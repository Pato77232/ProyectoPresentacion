# Proyecto Presentación Grupal - Los Backyardigans

## Descripción
Sitio web informativo que presenta al grupo de trabajo, incluyendo una página principal y una sección individual para cada integrante con su biografía, gustos y un minijuego interactivo.

## Como ejecutar el proyecto 
1. Clona el repositorio: `git clone https://github.com/Pato77232/ProyectoPresentacion.git`
2. Abre el archivo `index.html` en tu navegador.

## Frontend React y API Node
La portada React y el perfil de Edwin se ejecutan junto a las páginas HTML existentes. Para iniciar el API, abre una terminal en `backend` y ejecuta:

```bash
npm install
npm run dev
```

En otra terminal, inicia el frontend desde `fronted_presentacion`:

```bash
npm install
npm run dev
```

Abre `http://localhost:5173/fronted_presentacion/`. El frontend reenvía las solicitudes `/api` al servidor Node en `http://127.0.0.1:3000`.
